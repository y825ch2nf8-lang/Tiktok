# Analyse-Checkliste: Konkurrenz-Video vs. unser Video

Pro Punkt notieren: **die** (mit Beleg) / **wir** / **Änderung?**

| Bereich | Worauf achten |
|---|---|
| Erste Sekunde | Was sieht man im allerersten Frame? Bewegung sofort oder Standbild? Text schon da? |
| Hook | Wortlaut, Frage oder Behauptung, Länge, Position, Schriftgröße, Emoji |
| Mechanik | Ring/Escape, Rennen, Farbkampf, Wachsen, Verdoppeln, Physik-Rätsel („Will it fit?“) |
| Spannung | Was ist das offene Versprechen? Timer, Zähler, „Wait for the end“, Countdown |
| Tempo | Sekunden bis zum ersten Ereignis, Ereignisse pro 10 s, Beschleunigung zum Ende |
| Länge | Gesamtlänge; über 60 s (Creator Rewards) oder kurz für Loops? |
| Ende / Loop | Explosion, Auflösung, nahtloser Loop? Wird die Wiederholung bewusst provoziert? |
| Optik | Hintergrund, Farbpalette, Glow, 2D/3D (Blender?), Kamerabewegung, Partikel |
| Sound | Original-Sound oder Trend-Song? Noten pro Aufprall? Song-Aufbau? Lautstärke |
| Text im Video | Zähler, Labels, Schriftart, Lesbarkeit auf dem Handy |
| Caption | Frage, Länge, Hashtags (Anzahl, welche), Call-to-Action |
| Kommentare | Worüber reden die Leute? (Song raten, Gewinner tippen, „Teil 2“, Kritik an „Fake-Physik“) |
| Posting | Frequenz, Uhrzeit, Serien, Cross-Posting auf YouTube/Instagram |
| Zahlen | Follower, Likes gesamt, Views der Top-3-Videos, Verhältnis Likes/Views |

Am Ende: die 3 Unterschiede, die am wahrscheinlichsten die Views erklären. Begründung immer mit Beleg.
